# Ruleta de Arcanos

Aplicación web estática con 22 opciones y un PDF asociado a cada una.

## Uso

1. Colocar los 22 archivos PDF dentro de la carpeta `pdf`.
2. Nombrarlos `opcion-01.pdf` hasta `opcion-22.pdf`.
3. Abrir `index.html` o publicar la carpeta mediante GitHub Pages.

## Nota

Los PDFs deben estar disponibles en la misma ubicación que la aplicación para que el botón de descarga funcione correctamente.
